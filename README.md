### Featured Projects

**[LRU Cache — C++](https://github.com/aakashk7092)**
Implemented an O(1) Least-Recently-Used cache using a hash map + doubly linked list. Focus: constant-time get/put operations without sacrificing correctness under eviction.

**[LFU Cache — C++](https://github.com/aakashk7092)**
Extended the LRU design to track access frequency with LRU as a tie-breaker, keeping all operations O(1). Good exercise in combining multiple data structures to satisfy competing constraints.

**[ESP32 RFID Asset Tracking System](https://github.com/aakashk7092)**
A real-world IoT build using an ESP32 and RFID to track and log asset movement. Bridges my software work with hands-on hardware/embedded experience.
